A 2-block (or *K*-block) **Stochastic Block Model** whose mixing matrix is **not free**, but
derived from evolutionary game-theoretic **partner-choice equations**. Pointed at any binary
interaction network, the inference recovers both the community assignments *and* interpretable
payoff parameters that explain the network's block structure — with no neural network and no
training data.

The package provides two inference engines:

| Engine | Function | Description |
|---|---|---|
| Variational EM | `fit` | Constrained (game-theoretic) point estimate |
| Gibbs sampling | `fit_gibbs` | Constrained, full Bayesian posterior |
| Variational EM | `fit_free` | Free / unconstrained SBM baseline |
| Gibbs sampling | `fit_free_gibbs` | Free baseline posterior |

and the model-comparison diagnostics reported in the paper: **ELBO**, **MDL (BIC / Laplace)**,
the **Vuong test**, cross-validated **ΔELPD**, **WAIC**, **PSIS-LOO-CV**, and MCMC **R-hat / ESS**.
Fits run on **undirected or directed** networks, optionally **degree-corrected**, with a
**β sweep** to pick the inverse temperature and **human-readable game labels** for the result.

---

## The model

For a population with two types X and Y at frequencies `x` and `y = 1 − x`, payoff entries
`{a, b, c, d}`, and inverse temperature `β`, frequency-dependent softmax partner choice gives the
joint edge-type distribution **M**:

```
P_XX = x² · a^β / (x·a^β + y·c^β)      P_XY = xy · c^β / (x·a^β + y·c^β)
P_YX = xy · b^β / (x·b^β + y·d^β)      P_YY = y² · d^β / (x·b^β + y·d^β)
```

Only the cross-payoffs `b` and `c` are inferred; the diagonal is fixed by a **gauge**:

- `--gauge pin_diag`: `a = 2/3`, `d = 1/3` pinned. **This is the configuration used in the paper.**
- `--gauge row_sum`: each payoff row sums to 1, so `a = 1 − c`, `d = 1 − b`. This is the
  library default for K = 2 (it does not bake in an asymmetry between the two types); `pin_diag`
  is the default for K ≥ 3.

**M** is mapped to the SBM edge-probability matrix **B** through the graph density, so **B is fully
determined by `(b, c, β, x, y)`** — that constraint is what turns a purely statistical SBM into an
*explanatory* one. The free baseline (`fit_free`) lets B vary freely, as a reference point.

**Label orientation (canonicalization).** On an undirected graph the X↔Y relabelling is an
exact symmetry of the likelihood: the fit `(b, c, x)` and the swapped fit `(c·d/a, b·a/d, 1 − x)`
have identical ELBO, so which block is called X would otherwise be decided by the random seed.
By default (K = 2, `pin_diag`, `--method em`) the CLI reports the orientation with `c/b ≤ a/d`, i.e. **X is the
more homophilous block**, which is the convention used in the paper. Pass `--no-canonicalize`
for the raw fitted orientation. The ELBO and every model-comparison number are unaffected.

## Installation

The distribution and the CLI are named `gtbm`; the Python package is imported as
`constrained_sbm`.

```bash
pip install -e .
# optional: PSIS-LOO-CV support (everything else works without it)
pip install -e ".[loo]"
```

Requires Python ≥ 3.9. Dependencies: `numpy`, `scipy`, `networkx`, `scikit-learn` (and `arviz` only for PSIS-LOO-CV).

## Quick start

Run on **Zachary's karate club** (generated by networkx — no data file needed):

```bash
gtbm --dataset zachary                       # installed entry point
python -m constrained_sbm.run_inference --dataset zachary   # equivalent
```

The paper's fitting configuration is

```bash
gtbm --dataset zachary --gauge pin_diag --degree-corrected --n-spectral 4 --restarts 100
```

To choose β by maximum ELBO instead of fixing it (Brent's method over `[--beta-low, --beta-high]`,
about 10–15 EM fits):

```bash
gtbm --dataset zachary --gauge pin_diag --beta-sweep --beta-low 0.5 --beta-high 10
```

**Game labels.** For K = 2 the report names the recovered game (e.g. *Coordination*, *Stag Hunt*,
*Hawk-Dove*, *Harmony*) together with the two role labels (e.g. *Attractor / Satellite*). These
are the labels of the taxonomy introduced in Riedl & Smead (2026), Appendix section
"Game Taxonomy and Role Labels"; `constrained_sbm.game_label(a, b, c, d)` exposes the same mapping.

The quick-start command fits the constrained and free SBM by EM and prints the recovered payoffs, the joint
edge-type distribution **M**, the edge-probability matrix **B**, the ELBO gap, and the MDL / Vuong
comparison. Add `--cv-folds 10` for cross-validated ΔELPD, or `--method gibbs` for the full
Bayesian posterior with WAIC and PSIS-LOO-CV.

## Built-in example networks

No data files ship with this package. Two small classic networks are generated on the fly by
networkx and can be used by name:

```bash
gtbm --dataset zachary       # Zachary's karate club (34 nodes, 78 edges)
gtbm --dataset florentine    # Florentine families marriage network (15 nodes, 20 edges)
```

## Run GTBM on your own data

The model is **unsupervised**: supply only the graph, no node labels. Pass the file with
`--input PATH`; the format is chosen by the file extension.

| Extension | Format | Notes |
|---|---|---|
| `.npz` | `scipy.sparse.save_npz` adjacency matrix | square, any dtype; nonzeros are treated as edges |
| `.gml`, `.graphml` | networkx-readable GML / GraphML | node ids may be strings |
| anything else | plain-text edge list, one edge per line | **integer node ids**, whitespace-separated, lines starting with `#` ignored; extra columns (e.g. weights) are ignored; **always read as undirected** (use `.npz`, `.gml` or `.graphml` for a directed network) |

**Directed or undirected.** The input is *not* symmetrized by default. With `--directed auto`
(the default) an asymmetric adjacency is fitted as a directed network (the partner-choice flow
`M[I, J]` maps straight onto the arc probability `I → J`); a symmetric one is fitted as
undirected. Force a mode with `--directed yes` or `--directed no` (`no` merges an arc in either
direction into one undirected edge). In every case the graph is binarized and self-loops are
dropped; edge weights are discarded, so threshold a weighted network yourself first. Edge-holdout
cross-validation (`--cv-folds`) is available for undirected fits only. The empirical networks
analysed in the paper are not redistributed here; the paper lists their sources.

Example edge list (`network.txt`):

```
# source target
0 1
0 2
1 3
```

```bash
gtbm --input network.txt
gtbm --input network.gml --method gibbs
gtbm --input adjacency.npz --gauge pin_diag --degree-corrected --n-spectral 4 --restarts 100
gtbm --input network.txt --cv-folds 10 --out-json result.json
gtbm --input directed_network.npz --directed yes --gauge pin_diag --degree-corrected
```

Useful flags: `--K` (number of blocks), `--beta` / `--infer-beta` / `--beta-sweep`, `--gauge`,
`--degree-corrected`, `--directed`, `--canonicalize` / `--no-canonicalize`, `--restarts` and
`--n-spectral` (EM), `--n-samples` / `--n-chains` (Gibbs), `--out-json` to save the full report.
See `--help` for the full list.

From Python, build any `scipy.sparse` symmetric binary adjacency matrix and call `fit` directly
(see below); `constrained_sbm.utils.load_graph(path, symmetrize=False)` is the loader the CLI
uses (the default `symmetrize=True` merges arcs into undirected edges).

## Library usage

```python
import networkx as nx
from constrained_sbm import fit, fit_gibbs, fit_free

A = nx.to_scipy_sparse_array(nx.karate_club_graph(), format="csr", dtype=float)

# Variational EM (point estimate)
res = fit(A, K=2, beta=3.0, n_restarts=10)
print(res["b"], res["c"], res["x"])   # recovered payoffs and type-X frequency
print(res["M"], res["B"])             # joint edge-type dist. and edge-prob. matrix
print(res["elbo"])                    # evidence lower bound

# Gibbs posterior (credible intervals, R-hat / ESS in the returned dict)
post = fit_gibbs(A, K=2, beta=3.0, n_samples=1500, burn_in=750, n_chains=2)
print(post["posterior_summary"]["payoff_ci_95"])
```

`sweep_beta` (β search), `game_label` (taxonomy label) and `canonicalize_result` (orientation
convention, applied in place to a K = 2 `pin_diag` result) are exported as well.

Diagnostics are exposed directly too: `compute_model_comparison` (MDL / Vuong),
`compute_delta_elpd` + `compare_models` (cross-validated ΔELPD), `waic_from_loglik` /
`compare_waic`, and `loo_from_loglik` / `compare_loo`.
